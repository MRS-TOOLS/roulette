## 弱回線耐性と更新（2026-10-20）

取得済みの本体は通常オンライン・低速／不安定通信・完全オフラインともキャッシュから起動します。本体初期化とSW登録は広告より前に実行し、広告取得・DOMContentLoaded・window.loadを待ちません。広告タグ・IDと保存キー・形式は維持します。

新版の必要ファイルをすべて取得・保存してから採用し、使用中の画面をすべて閉じた後に切り替えます。本体を通信結果で個別上書きしません。HTMLの参照URL・SWの対象ファイル・キャッシュ名の版を一致させて更新してください。

キャッシュ欠損時は接続と本文取得を合わせて最大8秒で打ち切り、入口の取得失敗時は再試行を案内します。初回などSW未制御のページにはこの時間制限は適用されません。キャッシュ未取得・消失後はオンラインで準備してください。

検証：Node.js 24以降で `npm install --no-save --package-lock=false jsdom@30.1.3` の後、`node --test tests/*.test.cjs`。jsdomはテスト専用です。通信ハング・オフライン・更新失敗と、広告が応答しない状態の起動・保存復元を検証します。iPhone / Safari実機・ホーム画面起動・実広告表示は別途確認が必要です。
